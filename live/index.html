LIVE STUDIO

Central de entrada da SPRINT ISR. O conteúdo da aula é conduzido por um professor com passador/tablet; o operador técnico controla OBS, áudio e chat.

Conectar ao servidor LIVE

O LIVE Studio v1 opera num servidor Node.js separado. Este portal pode ser publicado no Command Center; a sincronização das aulas exige que o servidor esteja ligado.

No computador principal: http://127.0.0.1:8000. No tablet da mesma rede: http://IP-DO-NOTEBOOK:8000. Não use senha no endereço.

Abrir uma interface

Cada opção abre uma nova aba. A primeira inicialização solicita o código de controle nas interfaces autorizadas.

Primeiro acesso

1. Baixe o repositório e inicie a aplicação na pasta live-studio com Node.js 20+ e uma senha própria.

2. Salve aqui o endereço do servidor e abra Maestro e Direção Técnica em abas separadas.

3. Para os tablets, repita este endereço usando o IP do notebook na mesma rede local.

4. Faça o ensaio completo. O sistema v1 local não recebe votos de alunos conectados pela internet fora dessa rede.

Esta tela é um portal estático. Hospedá-la na Vercel não hospeda o servidor de sincronização e votação. Para a transmissão paga remota, é necessária infraestrutura online com persistência, autenticação e TLS.
