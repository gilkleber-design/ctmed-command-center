Modo colaborativo em tempo real

O arquivo funciona imediatamente em modo local. Para Gil e Diego usarem a mesma versão em computadores diferentes, publique este HTML (ex.: Vercel) e conecte um projeto Supabase.

Este protótipo é para gestão operacional. O exemplo abaixo usa um workspace ID compartilhado e políticas abertas ao cliente anônimo; não use para dados sensíveis.

Configuração única do Supabase. Execute no SQL Editor:

create table if not exists public.ctmed_state (
  room text primary key,
  data jsonb not null default '{}'::jsonb,
  updated_at timestamptz not null default now()
);

create table if not exists public.ctmed_messages (
  id bigint generated by default as identity primary key,
  room text not null,
  user_name text not null,
  message text not null,
  created_at timestamptz not null default now()
);

alter table public.ctmed_state enable row level security;
alter table public.ctmed_messages enable row level security;

create policy "ctmed_state_read" on public.ctmed_state for select to anon using (true);
create policy "ctmed_state_write" on public.ctmed_state for insert to anon with check (true);
create policy "ctmed_state_update" on public.ctmed_state for update to anon using (true) with check (true);
create policy "ctmed_messages_read" on public.ctmed_messages for select to anon using (true);
create policy "ctmed_messages_insert" on public.ctmed_messages for insert to anon with check (true);

alter publication supabase_realtime add table public.ctmed_state;
alter publication supabase_realtime add table public.ctmed_messages;
